A program that writes one original funny line — a robot vacuum's excuse for
missing a spot — to `/output/entry.txt`, an entry for
[The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7)
on make.fun. A house judge compares the lines pairwise on deadpan robot
voice, surprise, and tightness, with the punch at the end.

## The line

> I skipped that spot because my lidar detected a sock, and anything wearing a sock counts as a person. I do not vacuum people.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (125 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
